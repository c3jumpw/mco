Mark up a screenshot. Build a deck. Ship it as one file.

The PDF step is the problem.

Explaining something visual, a bug, a flow, a diagram, usually means projecting an image, circling a few things and writing notes around it. The usual tool is a slide deck.

Getting that deck anywhere else means exporting to PDF, and PDFs carry a hard page-count ceiling that trips up document uploads, including into language models. HTML has no such limit.

So HaloDeck cuts the middle out. Design in the browser, export one self-contained HTML file. Open it, upload it, present it, or reopen it later and keep editing.

How it works

Drop in

Paste a screenshot straight from the clipboard, or drag in one file or a whole folder from the desktop.

Mark it up

Circles, rectangles and arrows stack as reorderable, lockable layers. Click straight into any text layer and the cursor lands where you clicked.

Export

Pick the format and which slides go out. One HTML file with navigation and presenting built in, or a zip of images.

Built for one sitting, start to finish

No account, no backend, nothing to install.

Multi-slide canvas

Build out as many slides as the explanation needs, reordered by drag.

Layered annotations

Circles, rectangles and arrows stack as reorderable, lockable layers, so nothing you already placed shifts by accident.

Any page size

Widescreen, 4:3, square, vertical 9:16, 4:5 or A4, changeable at any point rather than chosen up front.

Notes per slide

Keep commentary as real exported text, or drop it onto the slide itself as a layer.

Export as one HTML file

Keyboard and swipe navigation, an all-slides view and full-screen presenting, with no page limit. Reopen it in HaloDeck to keep editing.

Export as zipped images

PNG or JPG at 1x or 2x, one per slide, plus a notes.txt. Exporting a single slide just gives you that image.

Pick which slides export

Every export opens a slide picker. All slides by default, shift-click for a range, or just the ones you need.

Autosaves as you work

Everything including images is kept in your browser, with no account. Save a portable project file to carry the work to another machine.

Practical details

  • RunsEntirely in the browser. No sign-up and no backend.
  • StorageAutosaves locally as you work, including images. A portable project file moves it between machines.
  • ExportsA self-contained HTML deck, or a zip of PNG or JPG images at 1x or 2x with notes.txt.
  • Designed forDesktop-first, built for a mouse and a big canvas, still fully usable on tablet or phone.
