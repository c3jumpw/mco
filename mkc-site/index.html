What we are building

A working collection of software and service brands, built and operated inside MK Holding Co. Each one started as a real problem somebody had.

  • Dispatch It Pocket capture for ClickUp. Say it once and it files itself in the right list. Progressive web app
  • DayForge Time-blocked daily planning, with notes, voice memos and files in one place. Web app
  • ContentFlow A content production board a whole organization works from. Web app
  • My PD A personal media library and knowledge vault, built for daily practice. Web app
  • Circuit Book Training routines planned by the week, run one full-screen card per set. Progressive web app
  • PingPath Personal outreach that remembers who has heard from you, and when. Web app
  • The Brand Craftsman Strategy, systems and brand positioning for business owners. Consulting

Most of these are not publicly listed. If one of them fits a problem you have, ask for a walkthrough, or tell us about something you would like to build with us.
